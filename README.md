# Yarik AI
A Discord bot designed to simplify interactions with LLMs (Large Language Models) by combining them into a single and fast Discord bot 
## Features
- Supports all APIs that have OpenAI compatible endpoint (basically all AI services have it)
- Seamless switch between models with a `/setmodel` command
- Support for Deno, Node, Bun, as well as their single executable variants
- Bundling to a single `bundle.cjs` file, which can be copied and runned anywhere without setting up dependencies
- Complex caching system with ability to configure how much messages to keep in it through `.env`
